# Agent Editors have narrower powers than human Editors

Human Editors can edit and delete Published news, and can delete categories. Agent Editors cannot. An agent can revise and delete Pending news, create and update categories, and set a featured image on Pending news. The news body is Markdown, and the byline stays with the Author who created it. Tags, navigation, publishing, and user management stay out. We kept a single Editor role and enforced the narrower powers on the MCP tools, rather than adding a third role or limiting human Editors.
